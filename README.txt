BIJVOEDING VOORRAAD 2.5.2 - VS CODE PROJECT

Mappen en bestanden:
- index.html             opbouw van het scherm
- css/style.css          alle vormgeving en kleuren
- data/defaults.js       opslagnaam, standaardproducten en standaardkamers
- js/app.js              werking, berekeningen, knoppen en weergave
- assets/                gereserveerd voor eventuele iconen/afbeeldingen
- original-2.5.2.html    originele werkende versie als reserve

Starten in VS Code:
1. Pak de ZIP uit.
2. Open de map 'bijvoeding-vscode' in VS Code.
3. Open index.html.
4. Test bij voorkeur met Live Server of via dezelfde GitHub Pages-methode als je andere app.

Belangrijk:
- De functies van versie 2.5.2 zijn niet bewust gewijzigd.
- Gegevens worden nog steeds lokaal in de browser opgeslagen via localStorage.
- De originele 2.5.2 zit als reservekopie in de map.
